# Smart Patient Analytics

A simple patient vitals dashboard with automatic risk scoring.

## Run
Open `index.html` in any web browser. No installation needed.

## Files
- index.html - page layout
- style.css  - styling (light and dark themes)
- script.js  - data, risk scoring (score()), rendering and events

## Risk rules (demo only, not medical advice)
Points for age, systolic BP, heart rate, temperature, SpO2 and glucose.
0-2 Low, 3-5 Medium, 6+ High.

Data is stored in memory only and resets on refresh.
